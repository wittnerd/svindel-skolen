# Kjennetegn på phishing

Se etter flere tegn, ikke bare ett enkelt tegn:

- Avsenderadressen virker uvanlig.
- Meldingen prøver å skape tidspress.
- En lenke ber deg logge inn eller oppgi informasjon.
- Språket eller hilsenen virker uventet.

!!! warning "Vær forsiktig"
    Ikke åpne lenker i mistenkelige meldinger. Gå heller til nettstedet ved å
    skrive adressen selv.
